Hermes

Hermes est un assistant personnel, utilisé par un seul utilisateur, pour publier sur sa propre chaîne YouTube les morceaux dont il détient les droits.

L'application utilise les services API de YouTube pour envoyer des vidéos et organiser des playlists, uniquement sur la chaîne du propriétaire, après son autorisation explicite.
